How the current score works
Current prototype score
Accessibility need 50% + Environmental risk 25% + Demographic vulnerability 25%. Each component is represented on a 0–100 scale.
Demographic vulnerability
Combines child share (0–6) and estimated elderly share (60+) equally. The elderly value is a temporary estimate using 9.55% of village population, not an actual village-level count.
Important data status
The current UI does not use the simulated unresolved-case file in the official score. It can be added later when a genuine health-record/outreach dataset is available.
Prototype for decision support. It does not replace health-administrator judgement. Accessibility values use the collected road-distance/duration data; environmental values use the collected flood/landslide risk data; child data comes from Census 2011, while elderly values are explicitly estimated.
