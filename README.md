# Health_Camp_Plannzer
SehatRoute is a data-driven decision-support system designed to help healthcare administrators identify and prioritize villages that may require last-mile healthcare outreach in Wayanad, Kerala.

The system combines multiple village-level factors such as healthcare accessibility, environmental risk, and demographic vulnerability to generate an explainable priority score for each village. Instead of relying on complex AI models, SehatRoute uses a transparent, configurable scoring approach so that users can understand why a particular village receives a higher priority.

The platform provides an interactive map and priority ranking that allow users to explore villages, view their nearest healthcare facilities, examine road distance and estimated travel time, and understand the factors contributing to their priority level.
